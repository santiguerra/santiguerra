### 🚀 Production Architecture & Real Projects / Proyectos en Producción

#### 🏋️‍♂️ [Faros Training Center](https://github.com/santiguerra)
> **Enterprise Sports Club Management & Booking PWA / PWA de gestión integral para club deportivo**
- **Stack:** `Next.js 15 (App Router)` `React 19` `Firebase Auth / Firestore / Storage` `Zustand` `Tailwind v4` `PWA`
- 🇺🇸 **Architecture:** 3-tier role system (Student, Coach, Admin). Sensitive financial transactions, subscription quotas, and class limits are calculated strictly server-side using **Firebase Admin SDK** (clients never declare amounts). Hardened Firestore security rules with atomic validations. Includes offline attendance taking with offline queue synchronization.
- 🇪🇸 **Arquitectura:** Sistema de 3 roles (Estudiante, Profesor, Admin). Flujo financiero y de suscripciones calculado 100% en el servidor mediante **Firebase Admin SDK** (el cliente nunca declara montos). PWA instalable con funcionamiento offline para toma de asistencia y sincronización automática.

#### 🍽️ [FoodSistem](https://github.com/santiguerra)
> **Real-time Table QR Ordering & Kitchen Operations SaaS / SaaS de pedidos QR en mesa y cocina**
- **Stack:** `React 19 + TypeScript` `Vite` `React Router 7` `Firestore Real-time` `Tailwind v4` `Vitest`
- 🇺🇸 **Architecture:** Zero-backend architecture with pure real-time event-driven Firestore synchronization across domains (`client`, `kitchen`, `cashier`, `admin`). Real-time order state machine (pending → prep → ready → served), waiter alerts, and daily cash closing reports adapted for Colombian currency (COP).
- 🇪🇸 **Arquitectura:** Arquitectura sincronizada en tiempo real mediante Firestore por dominios (`cliente`, `cocina`, `caja`, `admin`) con máquina de estados de pedidos en tiempo real, alertas de mesero y arqueos de caja diarios (COP).

#### 🧾 [ReceiptMaker](https://github.com/santiguerra)
> **School Cash Accounting System & PDF Engine / Sistema contable escolar y generador de recibos**
- **Stack:** `Next.js 15` `React 19` `Firebase App Hosting` `Firestore Transactions` `Tailwind v4`
- 🇺🇸 **Architecture:** Built around strict domain accounting rules: integer-cents calculations (zero float-precision errors), immutable historical receipt snapshots upon issuance, and atomic transaction reconciliation (issuing a receipt registers an account receivable, while marking it as paid triggers the actual cash flow atomically).
- 🇪🇸 **Arquitectura:** Diseñado con reglas contables de dominio estrictas: aritmética en enteros de centavos (cero discrepancias por redondeo float), snapshots inmutables de recibos históricos y conciliación transaccional atómica (emitir crea la cuenta por cobrar y marcar como pagado genera el movimiento de caja).

#### 🗄️ [Proactive Multitenant CRM](https://github.com/santiguerra)
> **AI-Driven Multitenant CRM with Relational Engine / CRM multitenant proactivo con motor relacional**
- **Stack:** `Next.js 15` `Firebase Data Connect` `PostgreSQL` `GraphQL` `Tailwind v4`
- 🇺🇸 **Architecture:** Modern 3-tier multitenant architecture (Agency → Subaccounts/Businesses → Contacts). Built with **Firebase Data Connect (PostgreSQL + GraphQL schema)**. Features autonomous WhatsApp sales tracking, automated appointment scheduling, and granular ROI attribution for AI-generated transactions (`isAIGenerated`).
- 🇪🇸 **Arquitectura:** Arquitectura multitenant de 3 niveles (Agencia → Subcuentas/Negocios → Contactos) construida sobre **Firebase Data Connect (PostgreSQL relacional gobernado por GraphQL)**. Trazabilidad de ventas y agendamientos automáticos con atribución directa de ROI para transacciones originadas por IA (`isAIGenerated`).

#### 🤖 [WhatsApp AI Ecosystem](https://github.com/santiguerra)
> **Applied LLM Pipelines & Multi-Agent Workflows / Automatización e IA aplicada sobre WhatsApp**
- **Automated Resume & Talent Screener (`filtro_hv_wpp`):**
  - 🇺🇸 End-to-end recruitment bot that processes incoming candidate CVs, extracts parameters, and scores them against job vacancy criteria using multi-LLM orchestration (**Gemini**, **Groq**, **Qwen**, and **xAI**).
  - 🇪🇸 Bot de selección de personal que extrae datos de hojas de vida y califica candidatos contra vacantes en tiempo real con orquestación multi-modelo (**Gemini**, **Groq**, **Qwen** y **xAI**).
- **Style Persona Cloning Engine (`mi_clon_wpp`):**
  - 🇺🇸 Prompt engineering engine that computes statistical linguistic metrics across years of chat logs (burst cadence, lexical habits) to replicate an authentic human writing style with custom output guardrails.
  - 🇪🇸 Motor de ingeniería de prompts que extrae métricas de estilo en años de chats para replicar una voz humana auténtica sin enviar historiales crudos al modelo.

#### ✈️ [Flight Tracker](https://github.com/santiguerra/flight-tracker)
> **Automated Airfare Scraper & Price Monitor / Rastreador y monitor de tarifas aéreas**
- 🇺🇸 Python scraping engine that continuously queries flight availability, tracks pricing volatility, and triggers automated alerts.
- 🇪🇸 Motor en Python para monitoreo recurrente de vuelos y alertas automáticas de mejores tarifas.
